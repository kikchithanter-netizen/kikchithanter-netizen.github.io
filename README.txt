Сайт Fantom

Как выложить на GitHub Pages:
1. Зайди на github.com и создай аккаунт (если его нет).
2. Нажми New repository, назови его, например, fantom, поставь Public и создай.
3. В репозитории нажми Add file -> Upload files и перетащи ВСЁ содержимое этой папки:
   index.html, папки css, js, audio, img (файл index.html должен лежать в корне, не внутри другой папки).
   Нажми Commit changes.
4. Открой Settings -> Pages. В Source выбери Deploy from a branch, ветка main, папка / (root), нажми Save.
5. Через 1-2 минуты сайт будет по адресу https://ТВОЙ_НИК.github.io/fantom/

Как поменять что-то самому:
- Тексты и ссылки: index.html
- Цвета и оформление: css/style.css
- Музыка и скрипты: js/main.js (список TRACKS в начале), файлы песен лежат в папке audio
